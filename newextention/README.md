# Focus roc'h

A Firefox extension that hides YouTube's distractions (home feed,
recommendations, end screens, comments...) so you can use YouTube on purpose.

Two modes, chosen after installation:
- **normal** (recommended): every setting applies at once;
- **hardcore**: reducing the protection is deliberately slow (focus timer,
  delay, weekly quota, locked hours); strengthening it is always instant.

Interface in English, French and Simplified Chinese.

Everything runs locally: no server, no tracking, no data sent anywhere.
